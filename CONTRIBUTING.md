# Contributing to AI Box Car Launcher

Мы рады любому вкладу в развитие открытого автомобильного лаунчера!

## Как внести вклад
1. Сделайте Fork репозитория.
2. Создайте ветку для вашей задачи: `git checkout -b feature/amazing-widget`.
3. Следуйте правилам чистого кода Kotlin и Jetpack Compose.
4. Убедитесь, что проект собирается без ошибок: `./gradlew assembleDebug`.
5. Откройте Pull Request с подробным описанием изменений и скриншотами (желательно в разрешении 1920x720 или 1920x1080 Landscape).

## Правила безопасности
- Никогда не коммитьте API-ключи (погодные сервисы, карты) и файлы ключей подписи (`*.jks`, `*.keystore`).
- Используйте `local.properties` или переменные окружения для локальных ключей.
- Исключение: `app/debug.keystore` намеренно хранится в репозитории — GitHub Actions использует его для стабильной подписи debug APK, чтобы обновления ставились поверх предыдущей сборки. Release-ключи коммитить запрещено.
