# AI Box Car Launcher (iPadOS Style)

Премиальный открытый автомобильный лаунчер для **Android AI Box** и автомобильных мультимедийных экранов (горизонтальная ориентация `Landscape 16:9+`), вдохновлённый эстетикой Apple iPadOS / iOS.

## Ключевые возможности
- **Два независимых рабочих стола (Home Screen 1 & 2)** с плавным переключением свайпом и свободной раскладкой виджетов.
- **Dock Bar с пространственной каруселью иконок** — центральный фокус, плавное масштабирование и прокрутка жестом, кастомные иконки. Перестановка иконок перетаскиванием пока не реализована: порядок задаётся по алфавиту.
- **Капсула системных кнопок (Back / Home / Recents)** — реальные системные действия Android (через `AccessibilityService` + fallback-механизмы для AI Box).
- **Динамические обои первого стола** — 8 плоских векторных сцен в едином стиле flat art (день, рассвет, ночь, дождь, снег, ветер, город, лес) с параллаксом и лёгкими погодными частицами. Второй стол остаётся с обычными обоями; доступны также фотосцены и «Живое небо».
- **Control Center (iOS Style)** & **App Drawer (Samsung DeX + iPadOS Style)**.
- **Система виджетов и полная персонализация** — сетка 6×10, 8 типов виджетов, галерея, drag & drop, смена размера, умный стек, кастомные PNG-логотипы без белого фона, скругления, тени, прозрачность, 8 тем обоев.
- **Паки иконок** — загрузка и применение кастомных паков.
- **Диагностика устройства** — SoC, GPU, RAM, OpenGL ES и живой замер FPS в разделе «Настройки → Диагностика».
- **Стекло в духе Apple Liquid Glass / iPadOS** — прозрачные панели, размытие фона, преломление кромки, блики, глубина и плавная реакция на нажатие; эффекты централизованы в `core-ui`.

## Статус разработки

Версия `0.12.1-alpha`. Уже работает: два рабочих стола с сеткой виджетов 6×10 (8 типов), меню всех приложений с поиском,
док с прокруткой и настраиваемым размером, погода с офлайн-кэшем и определением по GPS, фотосцены обоев по времени суток и погоде с параллаксом.
Есть шторка быстрого доступа, настройки в стиле iPad, свои и живые обои, паки иконок, обновление из приложения.
Ещё не сделано: спидометр, радио, компас, режим вождения, фоновое обновление погоды через WorkManager и подписанный release-APK. Виджеты «Заметки» и «Фото» пока показывают демо-содержимое. Раздел «Диагностика» добавлен, но показатели нужно проверять на конкретном AI Box. Усиленные стеклянные эффекты (blur, тень, блики) тоже стоит замерить на слабом железе: при просадках FPS уменьшайте `strength` панелей и отключайте динамические обои.
Подробности: [docs/ROADMAP.md](docs/ROADMAP.md) и [docs/SAFETY.md](docs/SAFETY.md).

## Архитектура проекта
Проект построен по многомодульной архитектуре (Kotlin + Jetpack Compose + Coroutines/Flow; настройки хранятся в SharedPreferences, зависимости Room/DataStore объявлены, но пока не используются):
```text
├── app/                # Точка входа: MainActivity (Home Launcher)
├── core/
│   ├── core-model/     # Доменные модели рабочих столов, элементов, тем, настроек
│   ├── core-data/      # Зависимости Room/DataStore (не используются), хранилище пока в SharedPreferences
│   └── core-ui/        # Дизайн-система, темы оформления, эффекты стекла
├── launcher/           # Координатор оболочки и состояния экранов
├── desktop/            # Home Screen 1 & 2, режим редактирования (Jiggle/Edit Mode)
├── dock/               # Нижняя панель и интерактивная карусель
├── widgets/            # Система виджетов (Погода, Музыка, Календарь, Часы, Батарея, Заметки, Фото, Умный стек)
├── wallpaper/          # Движок живых погодных и суточных обоев
├── weather/            # Провайдер погоды, кэширование и оффлайн-режим
├── control-center/     # Шторка быстрого управления в стиле iOS
├── app-drawer/         # Меню всех приложений в стиле Samsung DeX
├── settings/           # Полноценные настройки в стиле iPadOS (Split View)
├── icons/              # Загрузка и кастомизация PNG/WEBP иконок и логотипов
├── gestures/           # Модуль пока без исходников; жесты реализованы в Compose (desktop, dock, launcher)
└── system/             # AccessibilityService (Back/Home/Recents), PackageManager, Boot
```

## Сборка APK

### Требования
- JDK 17+
- Android SDK (compileSdk 35, minSdk 31 / Android 12+)
- Gradle 8.9+ (через `./gradlew`)

### Команды сборки
```bash
# Клонирование репозитория
git clone https://github.com/gyurdzhyan8631-netizen/aibox-ipad-launcher.git
cd aibox-ipad-launcher

# Один раз сгенерировать Gradle Wrapper (если нет gradlew)
gradle wrapper --gradle-version 8.9

# Сборка Debug APK
./gradlew assembleDebug

# Сборка Release APK (unsigned)
./gradlew assembleRelease

# Установка на подключённый AI Box через ADB
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## Настройка на Android AI Box
1. Установите APK на устройство.
2. Перейдите в **Настройки Android -> Приложения -> Приложения по умолчанию -> Главный экран** и выберите **AI Box Launcher**.
3. Для работы системных кнопок **Back** и **Recents** в капсуле разрешите службу **Специальные возможности (Accessibility)** для `AI Box Launcher`.
