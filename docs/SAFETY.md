# Безопасность интерфейса: чек-лист

Правила взяты из исследования (рекомендации NHTSA и смежные требования).
Статус — по текущей версии лаунчера (`0.12.1-alpha`), с учётом фотосцен обоев и стеклянных карточек.
Это ориентир для разработки, а не сертификация.

| Правило | Статус | Комментарий |
|---|---|---|
| Один взгляд ≤ 2 с, всего на задачу ≤ 12 с | не измерено | Нужны тесты на реальном экране (в т.ч. «окклюзионные»). |
| Действие за 1–3 нажатия | частично | Запуск приложения: 1 нажатие в доке, «Все» — 2. Настройки — 2. |
| Нет видео и автопрокрутки текста | ⚠ | Пользовательские видео-обои (`WallpaperType.VIDEO`) существуют. Перед релизом ограничить их или явно документировать как опцию. |
| Нет ввода текста в движении | ⚠ | Поиск в меню приложений и поле «Город» в настройках доступны всегда. План: блокировка по скорости. |
| Минимум сложных жестов | ⚠ | Есть свайп между столами, прокрутка дока, шторка свайпом. План: дублирующие кнопки. |
| Крупные цели нажатия | ⚠ | При минимальном размере панелей иконка дока: 46 dp × 0.75 ≈ 34.5 dp. Меньше 48 dp также кнопки редактирования виджетов, плеер и удаление в настройках. |
| Без тяжёлых эффектов (blur, тени в списках) | ⚠ | `glassSurface` теперь рисует размытие подложки (18 px), мягкую внешнюю тень со смещением 8 dp, преломление кромки и specular-блик; карточки Control Center — `shadowElevation = 16.dp`. Обязательно измерить FPS на слабом AI Box и при необходимости снизить `strength`. |
| Фон не анимируется покадрово | ⚠ | Динамические обои первого стола теперь векторные: параллакс идёт через `graphicsLayer`, а частицы — в отдельном Canvas ~24 кадров/с. У второго стола и в «Живом небе» остаются фотосцены, осадки и видео-обои — их влияние нужно мерить на слабом AI Box. |
| Офлайн-приоритет | ✅ | Погода и приложения работают без сети; устаревшие данные помечаются. |
| Постоянный маркер «это система автомобиля» | не сделано | Идея из исследования, пока не реализована. |
| Мультимодальные предупреждения (ADAS) | вне охвата | У лаунчера нет доступа к данным автомобиля. |
