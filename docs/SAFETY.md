# Безопасность интерфейса: чек-лист

Правила взяты из исследования (рекомендации NHTSA и смежные требования).
Статус — по текущей версии лаунчера. Это ориентир для разработки, а не сертификация.

| Правило | Статус | Комментарий |
|---|---|---|
| Один взгляд ≤ 2 с, всего на задачу ≤ 12 с | не измерено | Нужны тесты на реальном экране (в т.ч. «окклюзионные»). |
| Действие за 1–3 нажатия | частично | Запуск приложения: 1 нажатие в доке, «Все» — 2. Настройки — 2. |
| Нет видео и автопрокрутки текста | ✅ | Ничего подобного в интерфейсе нет. |
| Нет ввода текста в движении | ⚠ | Поиск в меню приложений и поле «Город» доступны всегда. План: блокировка по скорости. |
| Минимум сложных жестов | ⚠ | Есть свайп между столами, прокрутка дока, шторка свайпом. План: дублирующие кнопки. |
| Крупные цели нажатия | ⚠ | Основные кнопки крупные; при минимальном размере панелей иконки дока меньше 48 dp. |
| Без тяжёлых эффектов (blur, тени в списках) | ✅ | Используется один градиент и плоские карточки. |
| Фон не анимируется покадрово | ✅ | Цвет меняется плавно только при смене времени суток или погоды. |
| Офлайн-приоритет | ✅ | Погода и приложения работают без сети; устаревшие данные помечаются. |
| Постоянный маркер «это система автомобиля» | не сделано | Идея из исследования, пока не реализована. |
| Мультимодальные предупреждения (ADAS) | вне охвата | У лаунчера нет доступа к данным автомобиля. |
