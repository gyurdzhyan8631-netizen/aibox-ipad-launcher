# Дорожная карта AI Box Car Launcher

Составлена по выводам исследования «От iPadOS до рулевой колонки» (приоритеты: безопасность,
производительность на слабом железе, офлайн-приоритет, постепенный переход на модульный Compose).
Сам документ не содержит готового списка этапов, поэтому этапы ниже — рабочий план проекта.

## Уже сделано
- [x] Многомодульный каркас на Kotlin + Jetpack Compose, сборка APK на GitHub Actions.
- [x] Два рабочих стола: виджеты (Дата, Питание, Сеть) и сетка всех приложений.
- [x] App Drawer с поиском; док с прокруткой всех приложений; капсула Back / Home / Recents.
- [x] Док и капсула одной высоты, размер панелей настраивается.
- [x] Погода «офлайн-приоритет»: Open-Meteo без ключа, кэш на устройстве, метка «обновлено N мин назад», предупреждение «Нет связи» через 3 часа.
- [x] Обои: один градиент по времени суток и погоде, без покадровой анимации (минимум нагрузки на GPU).

## Дальше (по приоритету из исследования)
1. **Аудит железа** — экран «Диагностика»: SoC, GPU, RAM, версия OpenGL ES, замер FPS. Нужен, чтобы выбирать эффекты по фактам.
2. **Режим вождения** — источник скорости (GPS), блокировка ввода текста (поиск, город) и лишних жестов в движении.
3. **Крупные цели и 1 нажатие** — минимальная область нажатия 48 dp везде, кнопки-альтернативы свайпам.
4. **Виджеты для авто** — музыка (управление плеером), радио, спидометр, компас.
5. **Кэш погоды в Room + фоновое обновление через WorkManager** (сейчас упрощённо: SharedPreferences и обновление пока приложение живо).
6. **Персонализация** — 5 тем, кастомные иконки без белого фона, раскладка рабочих столов.
7. **Свой сервер Open-Meteo** (по желанию) — полная независимость от внешнего API.
8. **Релиз** — подписанный APK, workflow выпуска, проверка на реальном AI Box.
