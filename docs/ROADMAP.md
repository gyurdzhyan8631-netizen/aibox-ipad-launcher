# Дорожная карта AI Box Car Launcher

Составлена по выводам исследования «От iPadOS до рулевой колонки» (приоритеты: безопасность,
производительность на слабом железе, офлайн-приоритет, постепенный переход на модульный Compose).
Сам документ не содержит готового списка этапов, поэтому этапы ниже — рабочий план проекта.
Актуально для `0.12.1-alpha`: пункты «Дальше» не реализованы, если явно не указано иное.

## Уже сделано
- [x] Многомодульный каркас на Kotlin + Jetpack Compose, сборка Debug APK на GitHub Actions.
- [x] Два рабочих стола: сетка виджетов 6×10 (8 типов и умный стек); сетка приложений вынесена в App Drawer.
- [x] App Drawer с поиском; док с прокруткой всех приложений; капсула Back / Home / Recents.
- [x] Док и капсула одной высоты, размер панелей настраивается. Перестановка иконок перетаскиванием пока не реализована.
- [x] Погода «офлайн-приоритет»: Open-Meteo без ключа, кэш на устройстве, метка «обновлено N мин назад», предупреждение «Нет связи» через 3 часа; определение местоположения по GPS.
- [x] Шторка быстрого доступа и полноценные настройки в стиле iPad (темы, размеры, выбор приложений, доступ ко всем системным разделам).
- [x] Свои обои (фото, видео, системные живые), табло приложений как в DeX, обновление из приложения, паки иконок.
- [x] Обои: фотосцены по времени суток и погоде с параллаксом, цветокоррекцией и частицами; «Живое небо» и ручная фиксация состояния или режим «Авто». Нагрузку на GPU нужно измерить на реальном AI Box (см. SAFETY.md).

## Дальше (по приоритету из исследования)
1. **Аудит железа** — экран «Диагностика» добавлен: SoC, GPU, RAM, OpenGL ES и замер FPS интерфейса. Осталось проверить показатели на реальном AI Box и на их основе подобрать эффекты.
2. **Режим вождения** — источник скорости (GPS), блокировка ввода текста (поиск, город) и лишних жестов в движении.
3. **Крупные цели и 1 нажатие** — минимальная область нажатия 48 dp везде, кнопки-альтернативы свайпам.
4. **Виджеты для авто** — музыка (управление плеером), радио, спидометр, компас.
5. **Кэш погоды в Room + фоновое обновление через WorkManager** (сейчас упрощённо: SharedPreferences и обновление пока приложение живо).
6. **Персонализация** — паки иконок и свободная раскладка виджетов уже работают; осталось вернуть выбор «Стиля иконок» (пункт в настройках сейчас отключён).
7. **Свой сервер Open-Meteo** (по желанию) — полная независимость от внешнего API.
8. **Релиз** — подписанный APK, workflow выпуска, проверка на реальном AI Box.
