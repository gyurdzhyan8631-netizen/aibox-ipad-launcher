# Changelog

All notable changes to this project will be documented in this file.

## [0.4.0-alpha] - 2026-11-24
### Changed
- Вместо погоды в шапке — капсула значков: VPN, Wi-Fi (с числом подключённых), сотовая сеть, Bluetooth.
  Неактивные значки белые, активные VPN и Bluetooth — бирюзовые.
- Док без подписей: центральная иконка крупнее и «пружинит», соседние затемнены, после прокрутки иконка встаёт в центр.

## [0.3.0-alpha] - 2026-11-24
### Added
- Погода с офлайн-приоритетом (Open-Meteo, кэш на устройстве, метка возраста данных, предупреждение «Нет связи»).
- Окно «Настройки»: размер панелей и город для погоды.
- Документы `docs/ROADMAP.md` и `docs/SAFETY.md`.
### Changed
- Обои учитывают погоду; цвет меняется плавно и только при смене условий.

## [0.2.1-alpha] - 2026-11-24
### Changed
- Док и капсула кнопок теперь одной высоты; размер меняется ползунком («Размер» в доке).
- В доке слева закреплена кнопка «Все» (открывает табло приложений), все приложения прокручиваются.
- Виджеты рабочего стола подстроены под низкие экраны, на втором столе — все приложения.

## [0.2.0-alpha] - 2026-11-23
### Added
- Рабочие столы 1 и 2: виджеты (Дата, Питание, Сеть) и сетка приложений.
- App Drawer с поиском по приложениям.
- Загрузка списка приложений и кэш иконок (модуль `icons`).
- Кнопка Control Center в шапке теперь открывает шторку.
### Fixed
- Убран дубликат `control-center` и лишняя папка `src` в корне.
- CI сам создаёт и коммитит Gradle Wrapper.

## [0.1.0-alpha] - 2026-11-23
### Added
- Базовая многомодульная структура проекта (16 модулей).
- Система сборки Gradle Kotlin DSL (`build.gradle.kts`, `libs.versions.toml`).
- `AndroidManifest.xml` с поддержкой `HOME` / `DEFAULT` категорий лаунчера и `AccessibilityService`.
- Доменные модели (`DesktopItem`, `DockConfig`, `LauncherThemeStyle`, `WeatherScene`).
- Стартовый каркас интерфейса (Home Screen 1 & 2, Dock Carousel, System Capsule, Control Center, App Drawer, Settings).
- Шаблоны GitHub (Issues, Pull Requests, Release Workflow).
