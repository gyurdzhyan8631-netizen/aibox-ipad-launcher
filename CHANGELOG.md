# Changelog

All notable changes to this project will be documented in this file.

## [0.7.0-alpha] - 2026-11-25
### Added
- Раздел настроек «Размеры»: общий масштаб интерфейса и отдельные ползунки для часов, значков состояния,
  виджетов, дока, иконок и шторки быстрого доступа. По умолчанию интерфейс стал компактнее.
- Виджеты других приложений (часы, погода, плееры) можно добавлять на оба рабочих стола.
- Виджет «Все приложения» — сетка приложений прямо на рабочем столе.
- Мягкий эффект матового стекла на карточках, настройках, шторке, доке и виджетах.
### Changed
- Табло приложений — небольшой квадрат по центру, как в Samsung DeX (8 колонок, поиск внизу).
- С рабочих столов убрана надпись «Рабочий стол пуст».

## [0.6.0-alpha] - 2026-11-24
### Added
- Табло приложений в стиле Samsung DeX: светлая матовая панель над доком, сетка иконок с подписями, строка поиска.
- Шапка с приветствием (доброе утро / добрый день / добрый вечер / доброй ночи), тонкими часами и датой.
- Раздел «Обои»: свои фото, живые обои (видео), системные и живые обои Android.
- Раздел «Обновление»: проверка новой сборки на GitHub и установка поверх текущей.
- Виджеты «Погода» и «Музыка»; набор виджетов выбирается отдельно для каждого рабочего стола.
### Changed
- Второй рабочий стол — такой же полноценный, как первый (без списка приложений).
- Рабочие столы занимают весь экран, ничего не обрезается по краям.
- Шторка быстрого доступа стала компактнее.
- Сборки подписываются постоянным ключом, каждая публикуется как релиз «build-N».

## [0.5.0-alpha] - 2026-11-24
### Added
- Новая шторка быстрого доступа (свайп вниз от верха или значки в шапке): VPN, Wi-Fi, Bluetooth, мобильная сеть,
  музыка (предыдущий / пауза / следующий), ползунки яркости и громкости, ряд быстрых кнопок.
- Полноценные настройки в стиле iPad: разделы Главная, Wi-Fi, Bluetooth, Экран и яркость, Звук, Персонализация,
  Приложения, Система (быстрый доступ ко всем разделам настроек Android), О лаунчере.
- 8 тем оформления (в т.ч. «Авто (по солнцу)»), размер иконок / дока / часов, стиль часов,
  выбор музыкального приложения и навигатора, включение виджетов, показ приложений в доке.
### Removed
- Старое окно «Размер панелей» (заменено разделом «Персонализация»).

## [0.4.0-alpha] - 2026-11-24
### Changed
- Вместо погоды в шапке — капсула значков: VPN, Wi-Fi (с числом подключённых), сотовая сеть, Bluetooth.
  Неактивные значки белые, активные VPN и Bluetooth — бирюзовые.
- Док без подписей: центральная иконка крупнее и «пружинит», соседние затемнены, после прокрутки иконка встаёт в центр.

## [0.3.0-alpha] - 2026-11-24
### Added
- Погода с офлайн-приоритетом (Open-Meteo, кэш на устройстве, метка возраста данных, предупреждение «Нет связи»).
- Окно «Настройки»: размер панелей и город для погоды.
- Документы `docs/ROADMAP.md` и `docs/SAFETY.md`.
### Changed
- Обои учитывают погоду; цвет меняется плавно и только при смене условий.

## [0.2.1-alpha] - 2026-11-24
### Changed
- Док и капсула кнопок теперь одной высоты; размер меняется ползунком («Размер» в доке).
- В доке слева закреплена кнопка «Все» (открывает табло приложений), все приложения прокручиваются.
- Виджеты рабочего стола подстроены под низкие экраны, на втором столе — все приложения.

## [0.2.0-alpha] - 2026-11-23
### Added
- Рабочие столы 1 и 2: виджеты (Дата, Питание, Сеть) и сетка приложений.
- App Drawer с поиском по приложениям.
- Загрузка списка приложений и кэш иконок (модуль `icons`).
- Кнопка Control Center в шапке теперь открывает шторку.
### Fixed
- Убран дубликат `control-center` и лишняя папка `src` в корне.
- CI сам создаёт и коммитит Gradle Wrapper.

## [0.1.0-alpha] - 2026-11-23
### Added
- Базовая многомодульная структура проекта (16 модулей).
- Система сборки Gradle Kotlin DSL (`build.gradle.kts`, `libs.versions.toml`).
- `AndroidManifest.xml` с поддержкой `HOME` / `DEFAULT` категорий лаунчера и `AccessibilityService`.
- Доменные модели (`DesktopItem`, `DockConfig`, `LauncherThemeStyle`, `WeatherScene`).
- Стартовый каркас интерфейса (Home Screen 1 & 2, Dock Carousel, System Capsule, Control Center, App Drawer, Settings).
- Шаблоны GitHub (Issues, Pull Requests, Release Workflow).
